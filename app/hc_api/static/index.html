Cuatro vistas para verificar los casos de uso CU-01 a CU-15. Esta página la sirve la sede indicada arriba; lo que se registra aquí lo escribe esta sede y se replica a las demás.

Cómo se relacionan las sedes

Cada sede es dueña de las filas que crea y recibe una copia de solo lectura de las de las otras. Si una sede cae o queda aislada, las demás siguen mostrando su historia y la sede aislada sigue registrando lo suyo; al volver, todo se sincroniza solo.
